# CHP Reinforced Blocks

Аддон к **SecurityCraft** для Minecraft **1.20.1 / Forge 47**.
Делает так, чтобы **Универсальный укрепитель блоков** работал и с блоками **из других модов**
(Biomes O' Plenty, Macaw's, Dusty Decorations, Decorative Blocks и т. д.).

## Как это работает

SecurityCraft укрепляет только ванильные блоки: он заменяет блок на свою «укреплённую копию».
Этот мод работает иначе. Блок **не заменяется**, а укрепление запоминается **за местом**
(координатами) в сохранении мира. Поэтому:

* блок выглядит и работает как раньше: соединения, окна, люки и свет не меняются;
* если удалить мод, **ни один блок не пропадёт**, просто исчезнет защита;
* укреплённый блок не могут сломать:
  * другие игроки;
  * взрывы (крипер, TNT, гаст, иссушитель); укреплённая стена ещё и закрывает то, что за ней;
  * мобы (иссушитель, дракон, мобы из модов, которые ломают блоки);
  * огонь;
  * поршни;
  * чужое обтёсывание топором и похожие действия инструментами.

## Как пользоваться

* **ЛКМ укрепителем** по блоку из любого мода, и он укреплён (в строке над хотбаром будет «Блок укреплён»).
* **Ломать** укреплённый блок может только тот, кто его укрепил. Он ломает его обычным инструментом с обычной скоростью.
* **Снять укрепление** можно укрепителем 2 или 3 уровня в режиме «снятие укрепления»
  (ПКМ в воздух переключает режим, как в самом SecurityCraft) и ЛКМ по блоку.
* **Посмотреть, что укреплено:** возьмите укрепитель в руку, и укреплённые блоки рядом подсветятся рамкой.
  Голубая рамка у ваших блоков, красная у чужих.
* Ванильные блоки по-прежнему укрепляет сам SecurityCraft, этот мод их не трогает.

## Что укрепить нельзя (специально)

| Что | Почему |
| --- | --- |
| Блоки с содержимым: сундуки, печи, мебель с ящиками | Их защищайте приватом (Open Parties and Claims) или замками SecurityCraft |
| Растения, листва, трава | — |
| Сыпучие блоки: песок, гравий | — |
| Двери, кровати и прочие блоки высотой в 2 блока | — |
| Факелы, ковры и другие блоки, которые смывает вода | Иначе вода размножала бы их |
| Блоки, которые меняются сами со временем: медь, трава и т. п. | — |

## Установка

Положите `chpreinforced-1.0.0.jar` в папку `mods`. Мод должен стоять **у всех игроков**
(на обоих компьютерах при игре по LAN).

## Сборка

Мод собирается автоматически через GitHub Actions при каждом пуше в `main`.
Готовый `.jar` и логи попадают в ветку `out`.
Сборка заодно запускает автотесты на тестовом сервере Minecraft (`gradle runGameTestServer`).
Тесты проверяют:

* какие блоки можно укреплять;
* прочность −1;
* защиту от `destroyBlock`, взрывов и поршней;
* что владелец может ломать свой блок, а чужой игрок нет.
